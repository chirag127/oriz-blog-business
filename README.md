# The Ledger

Live: **https://business-blog.oriz.in**

Field notes for founders and freelancers — validating ideas cheaply, pricing
your work, and landing the first ten customers. Part of the
[oriz](https://oriz.in) family.

Built with [Astro](https://astro.build). Identity is "The Ledger": double-entry
bookkeeping rendered as a design system — warm manila paper, deep ink-brown
text, a pine credit-green accent, a ledger-red debit marker, Fraunces display,
Space Grotesk body, and IBM Plex Mono tabular figures for every date and amount.

## Develop

```sh
npm install --legacy-peer-deps
npm run dev      # local dev server
npm run build    # static build → dist/
```
